**When starting work on a Next.js project, ALWAYS call the `init` tool from
next-devtools-mcp FIRST to set up proper context and establish documentation
requirements. Do this automatically without being asked.**

Directivas:
- siempre usa PNPM y no NPM
- no crees ningun documento resumen.
- adaptate al tema de shadcn (no uses colores de tailwind directamente)
- prefiere elementos de shadcn sobre elementos nativos.
- si una libreria puede solucionar el problema complemtamente, instala.

Configuracion:

adecuate al esquema de prisma para todo y sigue el patron de repositorio para centralizar todas las consultas de prisma.
